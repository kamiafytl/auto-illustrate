# 轻量机翻界面（tools/mt）

**它是什么**：一个随手可开的**本地网页机翻工具**——粘贴任意文本，走 DeepSeek 出译文。
零依赖（Python 标准库）、启动 <1 秒、与 webapp/vite 完全无关。

**它不是什么（边界·重要）**：
- **不是 tag 翻译通道**。danbooru tag 的中译走 `webapp/server/plugins/translate.ts` + `data/translation_config.json`（另一把 key + 缓存），两者**各用各的额度、互不影响**。
- **不做批量/管线**。本工具用的是朋友提供的**低余额 key**（`data/mt_config.json`，gitignored），只供人工随手翻译；批量翻译、生产管线一律别接这里。
- 不写任何项目数据文件，纯读写内存 + 浏览器 localStorage（只记住上次选的方向/模型）。

## 用法
**正式入口 = 桌面「控制面板」→ 工具 → 机翻**（「打开」幂等：没跑就拉起、已跑只开页面；另有「余额」「停止」）。
面板改完要跑 `bash tools/deploy_launcher.sh` 才会同步到桌面。

| 备用方式 | 命令 |
|---|---|
| WSL 命令行 | `bash tools/mt/start.sh` |
| Windows 双击 | `tools/mt/机翻.bat` |
| 单独桌面快捷方式 | `powershell.exe -ExecutionPolicy Bypass -File tools/mt/deploy_shortcut.ps1`（默认不装，入口在控制面板） |
| 前台调试 | `python3 tools/mt/server.py --port 8848 --open` |

页面：http://127.0.0.1:8848/ （Windows 侧可直连，已实测）｜ 停止：`fuser -k 8848/tcp`

## 界面
- 方向：自动 / →中文 / →日语 / →English
- **Enter 直接翻译**，Shift+Enter 换行；输入法组词中的 Enter（选字）不会误触发
- 模型：`flash`(默认·便宜) / `pro`(更准更贵)，右上角实时显示**账户余额**，译文栏显示本次 token 与**估算花费**
- 附加要求框：临时指令（如「口语化」「保留敬语」「保持编号格式」）
- 快捷键：`Ctrl+Enter` 翻译 ｜ `Ctrl+Shift+C` 复制译文 ｜ `Esc` 中断 ｜「粘贴」按钮 = 读剪贴板并立刻翻译

## 自动方向的判定逻辑（服务端代码判，不问模型）
`server.py::detect_lang()` 按 Unicode 区段数字符，**优先级短路**，先命中先返回：

| 顺序 | 命中条件 | 判为 | 备注 |
|---|---|---|---|
| 1 | 有平假名/片假名 `U+3040–30FF`（排除中点 `・`） | 日语 | 中日混排也算日语——有假名必是日文句 |
| 2 | 有谚文 | 韩语 | |
| 3 | 无假名但有日语专用字形（`発売駅変実図円伝働仮…` 及 `々〆ヶ`） | 日语 | 补「整句无假名的日语」盲区，如「今日出発」；这些字形简体繁体中文都没有 |
| 4 | 有汉字 | 中文 | 繁体也归中文 |
| 5 | 有西里尔字母 | 俄语 | |
| 6 | 有拉丁字母 | 英语 | |
| 7 | 都没有（纯数字/符号） | 未知 | |

译向表 `AUTO_ROUTE`：**日→中、中→日，其余一律→中**。判定结果实时显示在译文栏（「日语 → 中文」），判错就直接点方向按钮手动指定。
手动模式下也会检测源语种，只用于显示；源=目标时改为润色级改写。

**已知盲区**：整句纯汉字、又不含上表第 3 行那些日语专用字形的日文（如「一日一善」），会被判成中文而译向日语。看到方向不对，手动点一下即可。

## 安全
- api_key 只在服务端读取，**绝不下发浏览器**（同 translate.ts 红线）。
- 仅监听 `127.0.0.1`，外部访问不到。
- `data/mt_config.json` 与 `tools/mt/.server.log` 均已 gitignore，禁入 git/memory。

## 成本参考（v4-flash，元/百万 token：入 0.5 / 出 1.5）
flash 是推理模型，一句话约 200~700 输出 token ≈ **¥0.0005/次**；7 元余额够上千次随手翻译。
长文/追求质量再切 pro（贵 8 倍）。
